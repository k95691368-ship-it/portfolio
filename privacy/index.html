3. 보유기간과 파기

  • 지원서와 제출자료: 지원 접수 후 3년. 그 전에 삭제를 요청하면 본인과 법적 보존 필요 여부를 확인한 후 지체 없이 파기합니다.
  • 계정과 일반 이용 기록: 계정 이용 및 관련 업무에 필요한 동안 보관하고, 탈퇴·삭제 요청 또는 처리 목적 종료 시 관련 자료와 법적 보존 필요 여부를 함께 확인합니다. 탈퇴만으로 법적 보존 대상 계약 기록까지 즉시 삭제되지는 않습니다.
  • 체결된 근로계약서 및 관련 증빙: 사용자에게 적용되는 근로기준법 제42조와 같은 법 시행령 제22조에 따른 보존을 지원합니다. 근로계약서의 보존 기준은 근로관계 종료일부터 3년이며, 종료일이 등록되지 않은 기록은 기간 만료를 자동으로 판단하지 않습니다.
  • 면접 녹화: 녹화 종료일부터 30일을 보관 기준으로 사용하며, 만료된 녹화의 접근을 제한합니다. 접근 제한과 저장파일의 물리적 삭제는 별개입니다.
  • 로그인 세션: 로그인 유지 선택에 따라 30일 또는 12시간, 개발자 체험 세션은 1시간 동안 유효합니다. 세션 만료는 해당 계정이나 작성한 공고의 삭제를 의미하지 않습니다.
  • Gmail 연결 인증정보: 발송 계정 연결을 유지하는 동안 보관합니다. 연결 해제 시 Google 권한 철회와 서버에 저장한 인증정보 삭제를 함께 처리합니다.

현재 모든 자료를 기한 만료와 동시에 자동 삭제하는 시스템은 아닙니다. 운영자가 보관기간·목적 종료·삭제 요청을 확인하여 데이터베이스와 파일 저장소의 관련 자료를 삭제하는 방식으로 처리합니다. 별도 법령에 따라 보존할 자료는 해당 근거와 기간을 확인하고 다른 목적으로 사용하지 않습니다.

전자파일은 서비스의 데이터베이스 및 저장소 삭제 절차로 파기합니다. 백업·서비스 제공자의 보안 로그에 남은 사본은 해당 제공자의 보관·삭제 절차에 따라 처리되며 즉시 일괄 소거를 보장하지 않습니다. 이미 수신자에게 전달된 이메일과 내려받은 파일은 서버에서 삭제해도 수신자의 사본까지 회수되지 않습니다.

4. 열람 및 제공 대상

지원한 공고의 채용 담당자는 심사에 필요한 지원서와 첨부자료를 볼 수 있습니다. 면접과 계약 자료는 해당 절차에 참여하고 권한을 가진 당사자 및 운영상 필요한 권한을 가진 관리자에게 제공됩니다. 면접관 협의 내용은 지원자용 공개 채팅과 구분하여 처리합니다.

공개 공고는 누구나 볼 수 있습니다. 발급번호를 가진 사람은 공개 증명서 진위 확인 기능을 이용할 수 있으므로, 발급번호와 면접방 입장 코드·지원 접수번호를 공개 게시하지 마세요.

운영자는 개인정보를 판매하지 않습니다. 채용 절차와 무관한 제3자 제공은 별도의 동의 또는 법령상 근거 없이 하지 않습니다. 실재하지 않는 업체를 대상으로 동의를 받지 않습니다.

5. 외부 서비스 처리와 국외 처리

서비스 제공을 위해 다음 인프라와 API를 사용합니다. 단순히 이 방침을 읽거나 사이트를 방문한 것만으로 별도의 개인정보 제공·국외이전 동의를 받은 것으로 보지 않습니다.

Supabase — 데이터베이스·서버 기능·파일 보관·실시간 메시지
계정, 지원서, 면접·계약 기록, 첨부파일과 서버 인증정보를 처리합니다. 현재 프로젝트 데이터베이스의 선택 지역은 대한민국 서울(ap-northeast-2)입니다. 이것이 모든 서버 실행·지원·보안 로그가 국내에서만 처리된다는 뜻은 아닙니다. 개인정보 안내 · 데이터 처리 조건
Cloudflare — 사이트 배포·콘텐츠 전송·접속 보호
웹페이지를 전달하면서 IP 주소, 요청 URL, 브라우저 및 접속 정보를 처리합니다. 미국 사업자가 운영하는 글로벌 네트워크를 사용하며, 이 사이트의 지원서·계약서 데이터베이스는 Supabase에 둡니다. 개인정보 안내
Google — Gmail 발송
Gmail 연결이 활성화되면 발신 계정 인증정보, 수신 이메일, 제목·본문·선택한 첨부파일을 발송 요청 시 HTTPS로 전송합니다. 미국 등 Google의 서비스 운영 국가에서 처리될 수 있으며, 발송 메일은 발신·수신 메일함에도 남습니다. 개인정보 안내
Anthropic — AI 보조 기능
AI 기능이 설정되어 실행될 때 필요한 입력 내용과 출력 결과를 처리합니다. 미국 사업자의 API를 사용합니다. Gmail 인증 토큰이나 받은편지함을 제공하지 않습니다. 개인정보 안내

이전·처리는 해당 서비스 요청 시 네트워크를 통해 이루어집니다. 플랫폼에 저장한 자료의 보관 기준은 제3항을 따르며, 제공자 자체 로그·백업의 보관과 글로벌 처리 위치는 각 제공자의 계약·정책에 따릅니다. 위 목록은 현재 확인된 처리 구조이며, 계약별 전체 처리 국가·재수탁자·로그 보관 설정을 확정한 국외이전 동의서가 아닙니다. 국외 처리에 대한 확인·거부·삭제 요청은 운영자에게 문의할 수 있고, 필수 처리에 동의하지 않거나 적법한 처리 근거가 확보되지 않으면 해당 기능의 이용이 제한될 수 있습니다.

6. Gmail API 데이터 이용

Gmail API는 운영자가 직접 승인한 발신 계정에서 채용 관련 메일을 보내기 위해 사용합니다. 지원자가 Google 계정을 연결할 필요는 없습니다. 사용하는 권한은 gmail.send이며, 받은편지함 읽기, 연락처 조회, 기존 메일 삭제 권한은 요청하지 않습니다.

서버는 OAuth 클라이언트 정보와 갱신 토큰으로 단기 접근 토큰을 발급받아 메일을 전송합니다. 인증정보는 서버 비밀 설정에 보관하며 공개 코드·웹페이지·브라우저 저장소에 넣지 않습니다. Gmail의 응답은 발송 처리 결과 확인에 사용합니다. API 요청 성공은 수신자의 받은편지함 도착이나 열람을 보장하지 않습니다.

Google API에서 받은 정보의 이용 및 다른 앱으로의 전송은 Google API Services User Data Policy와 그 Limited Use 요건을 준수합니다. Google 사용자 데이터를 광고 타기팅, 판매, 범용 AI 모델 학습에 사용하지 않습니다. 필요한 기능 제공, 이용자가 동의한 지원, 보안 대응 또는 법령상 의무 이외의 목적으로 사람이 열람하지 않습니다.

운영자는 Google 계정의 연결 관리에서 권한을 철회할 수 있습니다. 권한 철회 후에는 새 발송이 중단될 수 있으나 이미 보낸 메일과 플랫폼의 업무 기록까지 자동 삭제되지는 않습니다.

7. 쿠키·브라우저 저장소와 이용 분석

로그인과 면접방 이용을 위해 브라우저의 localStorage 또는 sessionStorage에 세션 토큰·만료시각·방 접근 방식과 알림 설정을 저장합니다. 브라우저의 사이트 데이터 삭제 또는 로그아웃으로 로그인 정보 등을 지울 수 있으며, 삭제하면 다시 로그인하거나 입장해야 할 수 있습니다.

녹화를 진행하는 브라우저의 IndexedDB에 복구용 영상·음성 조각을 임시 저장합니다. 서버 업로드와 완료 처리가 확인되면 임시 사본을 제거합니다. 중단된 사본은 마지막 저장 후 30일이 지난 뒤 이 브라우저에서 녹화 시작 또는 복구를 다시 실행할 때 정리합니다. 브라우저를 다시 사용하지 않으면 기한과 동시에 삭제되지는 않습니다. 공용 기기에서는 이용 후 사이트 데이터를 삭제해야 하며, 삭제한 임시 사본은 복구할 수 없습니다.

Google Analytics와 Microsoft Clarity의 외부 분석 스크립트 로딩을 중단했습니다. 지원서·계약서·면접 화면과 조회용 주소를 이 도구들로 전송하지 않습니다.

과거에 외부 분석 도구로 처리된 기록은 각 제공자의 보관 정책에 따릅니다. 신규 로딩 중단이 과거 기록의 삭제를 의미하지 않습니다.

8. 이용자와 법정대리인의 권리

본인 또는 적법한 대리인은 개인정보의 열람·정정·삭제·처리정지와 동의 철회를 이메일로 요청할 수 있습니다. 운영자는 요청자 확인에 필요한 최소한의 정보를 확인하고 관계 법령에 따라 처리 결과 또는 제한 사유를 안내합니다. 법령상 보존 의무나 타인의 권리 보호 때문에 즉시 삭제할 수 없는 기록이 있을 수 있습니다.

AI 요약·평가 내용에 대한 설명과 오류 정정, 사람이 직접 검토해 줄 것을 요청할 수 있습니다. 채용 결정은 해당 채용 담당자가 수행하며, 자동 점검 결과가 법원이나 행정기관의 판단을 대신하지 않습니다.

만 14세 미만 아동을 위한 법정대리인 동의 절차는 제공하지 않습니다. 해당 아동의 정보가 제출된 사실을 알게 된 경우 운영자에게 연락하면 확인 후 필요한 보호·삭제 조치를 진행합니다.

9. 안전성 확보 조치

HTTPS 통신, 비밀번호 해시 저장, 서버의 역할·참여자별 접근 검사, 세션 만료, 파일 접근 제어, 요청 횟수 제한, 서명과 문서 지문·변경 이력 기록을 적용합니다. Gmail 인증정보와 서비스 비밀키는 서버에서 관리합니다. 모든 침해 가능성이 제거되거나 전 구간 종단간 암호화가 제공된다고 보장하지는 않습니다.

10. 변경 및 권리 구제

처리 목적·항목·제공 대상 등 중요한 내용이 바뀌면 시행일과 변경 내용을 사이트에서 알리고, 관계 법령상 별도 동의나 고지가 필요한 경우 해당 절차를 진행합니다.

개인정보 관련 상담은 개인정보침해 신고센터(국번 없이 118), 분쟁 조정은 개인정보분쟁조정위원회(1833-6972)를 이용할 수 있습니다.
