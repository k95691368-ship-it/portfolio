# AI 채용 · 전자근로계약 플랫폼

채용 공고를 올리는 순간부터 근로계약서를 보관하고 증명하는 순간까지를 하나로 이은 서비스입니다.

**[portfolio-epa.pages.dev](https://portfolio-epa.pages.dev)** · 첫 화면에 1시간 체험 안내가 있습니다.

---

## 왜 만들었나

작은 사업장에는 노무를 봐줄 사람이 없어 모른 채 법을 어기고, 근로자는 자기가 무엇에 서명하는지 모르며, 나중에 다투게 되면 증명할 방법이 없습니다. 이 세 가지에서 출발했습니다.

## 무엇을 하는가

계약 조건을 입력하면 **최저임금**, **주 52시간**, **근로기준법 제17조 명시사항**, **기간제 2년 상한**, **지원할 때 본 공고와의 차이**를 자동으로 계산해 알립니다.

위법한 계약은 경고에 그치지 않고 **서버가 서명 자체를 막습니다.** 화면을 우회해 직접 요청을 보내도 거부됩니다.

서명할 때는 그 시점의 계약 내용을 지문(SHA-256)으로 만들어 서명과 함께 남기고, 이후 내용이 바뀌면 그 서명을 무효로 돌립니다. 체결이 끝나면 계약 이력을 발급번호가 붙은 **감사추적증명서**로 떼어내, 근로조건은 감춘 채 로그인 없이도 진위를 확인할 수 있게 했습니다.

## 전체 흐름

```
채용 공고 게시
  → 로그인 없이 지원 (접수번호 발급)
  → 서류 심사 · 지원자 비교
  → 면접방 대화
  → 화상 면접 (녹화 동의 · 공개 대화 · 면접관 협의)
  → 계약 조건 작성
  → 서명 전 법령 점검      ← 위반 시 서명 차단
  → 전자서명 (문서 지문 결합)
  → 교부 기록 · 열람 시각
  → 감사추적증명서 발급
  → 로그인 없는 진위 확인
```

## 다루는 법령

| 법 | 무엇을 확인하는가 |
| --- | --- |
| 근로기준법 제17조 | 서면 명시사항 12개 누락, 교부 의무 |
| 근로기준법 제42조 · 시행령 제22조 제2항 | 3년 보존, 기산일은 근로관계가 끝난 날 |
| 근로기준법 제54조 · 제55조 · 제60조 | 휴게, 휴일, 연차 |
| 최저임금법 | 월 소정근로시간 환산 후 시급 비교 (2026년 10,320원) |
| 기간제법 제4조 | 2년 상한, 이어진 계약의 계속근로 합산 |
| 채용절차법 제4조 제3항 | 공고보다 불리하게 변경되었는지 대조 |
| 전자문서법 제5조 | 수신 기록 |

## AI를 쓰는 곳과 쓰지 않는 곳

판단이 필요한 **서류 심사 · 대화에서 근로조건 추출 · 계약서 문장 작성 · 번역(10개 언어)** 에는 Anthropic API를 씁니다.

반대로 **최저임금 · 근로시간 · 계약 기간 계산은 AI를 쓰지 않습니다.** 법적 판정은 같은 계약이면 언제나 같은 답이 나와야 하고, 재현되지 않는 판정은 근거가 될 수 없기 때문입니다.

## 기술 구성

- **배포** Cloudflare Pages (정적 프런트엔드만)
- **백엔드** Supabase Edge Functions · PostgreSQL · Storage · Realtime
- **화면** React 19 · Vite
- **인증** PBKDF2-SHA256, 세션 토큰은 해시로만 저장
- **테스트** 단위 테스트 · 배포 환경 읽기 점검 · 운영 전 과정 검증

## 직접 실행하려면

```bash
npm install
npm run dev
```

AI 기능을 쓰려면 Anthropic API 키가 필요합니다.

```bash
Supabase 프로젝트의 Edge Function secret에 `CLAUDE_API_KEY`를 등록합니다.
```

법령 점검 · 전자서명 · 교부 · 증명서는 API 키 없이도 동작합니다.

## 화상 면접 운영 설정

화상·음성은 브라우저 WebRTC로 직접 연결하고, 참가자 발견과 SDP/ICE 신호는 Supabase Realtime Broadcast/Presence로 전달합니다. 녹화 파일은 브라우저에서 합성한 뒤 Supabase Storage의 만료형 서명 업로드와 TUS 재개 업로드를 통해 `interview-recordings` 비공개 버킷에 보관합니다.

- 진행자만 녹화를 시작·일시정지·종료할 수 있습니다.
- 녹화 필수 일정은 현재 안내문에 동의한 참가자에게만 입장 정보를 발급합니다.
- 면접관 협의 중에는 지원자와 면접관 사이의 송신 오디오 트랙을 끊고, 면접관 비공개 대화는 WebRTC 데이터 채널로 대상 면접관에게만 보냅니다.
- 공개 대화는 기존 면접 기록 API를 통해 PostgreSQL에 남깁니다.
- 녹화는 30일 보관 후 삭제하며, 파일 크기와 SHA-256 지문을 데이터베이스에 기록합니다.
